# padel-ecommerce

Plataforma Back-End desarrollada en Java y Spring Boot para la gestión integral de una tienda online especializada en artículos de pádel.
El sistema proporciona una API REST para el registro y autenticación de usuarios, administración de catálogo de productos, gestión de carritos de compra y procesamiento de pedidos.
Tambien incluye funcionalidades para la publicación de reseñas y calificaciones de productos, ofreciendo una solución completa y modular para el comercio electrónico deportivo.


Entre las principales funcionalidades se encuentran:

- Registro y autenticación de usuarios.
- Consulta y administración del catálogo de productos de pádel.
- Creación y gestión del carrito de compras.
- Creación y seguimiento de pedidos.
- Publicación de reseñas y calificaciones sobre productos.
- Gestión de información de usuarios y productos.
- Validación de datos recibidos mediante las solicitudes de la API.
